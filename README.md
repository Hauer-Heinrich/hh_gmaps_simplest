# hh_gmaps_simplest
hh_gmaps_simplest is a TYPO3 Google-Maps-API extension.

### Installation
... like any other TYPO3 extension [extensions.typo3.org](https://extensions.typo3.org/ "TYPO3 Extension Repository")
Don't forget to include PageTS.
You need a GoogleMaps API-key, and optional a GoogleMaps "mapId"!

### Features
to use the map config in your own extension or for example tt_address, you have to include the code like:
"EXT:hh_gmaps_simplest/Resources/Private/Templates/Gmaps.html"
#### IMPORTANT
The class-name on element: "script identifier="hh-gmaps-simplest-config" has to be "hh-gmaps-simplest-config"
